<h1>Gerenciador de Livros</h1>
<p>Um simples projeto para treinar conceitos de operações CRUD</p>
<hr>
<h3>Tecnologias e Conceitos Utilizados:</h3>
<ul>
  <li>SpringBoot</li>
  <li>Spring WEB</li>
  <li>H2 DataBase - Baseado em memória</li>
  <li>JPA - Json Persistance API</li>
  <li>DTO - Data Transfer Object</li>
  <li>Lombok - Para annotations Boilerplate</li>
  <li>Arquitetura por Camadas</li>
</ul>
